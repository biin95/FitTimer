# FitTimer 💪⏱️

健身训练记录 + 组间休息计时器 Android App

## 功能特性

### 🏋️ 训练记录
- 按日期记录每次训练（日历首页，点击日期进入训练页）
- 力量训练：记录动作名称、组数、重量、次数
- 有氧训练：记录时长、距离、速度、坡度
- 训练中实时勾选完成组，自动记录实际重量和次数
- 草稿保存：未完成的训练自动保存，下次继续

### 📋 模板系统
- 保存常用训练方案为模板
- 一键套用模板开始训练
- 支持编辑和删除模板

### 📖 动作库
- 内置 35+ 个健身房常见训练动作
- 按肌群分类：胸、背、腿、肩、手臂、核心、有氧
- 每个动作配有 GIF 动图演示
- 详细的动作说明：目标肌群、动作步骤、训练要领
- 左侧分类 + 右侧列表的 Master-Detail 布局

### ⏱️ 组间休息计时
- 可配置休息时长（默认 90 秒）
- 前台服务通知：锁屏 / 切后台计时不中断
- 息屏震动提醒（AlarmManager + USAGE_ALARM，系统级精确触发）
- 可配置震动时长（1 / 3 / 5 秒）
- 训练语音 / 震动提示休息结束

### 📊 数据统计
- 三个统计维度：本周 / 本月 / 自定义日期范围
- 训练概览：训练次数、动作数、总组数
- 本周 / 本月完成次数
- 个人记录（PR）：最佳重量，自动过滤有氧运动
- 月度训练频率柱状图（最近 6 个月）
- tab 切换零延迟（数据预加载 + 缓存）

### 🌤️ 天气显示
- 首页实时天气（和风天气 API）
- GPS 定位 + 高德 IP 定位（室内 fallback）
- 6 小时缓存，每日首次加载获取

### 📤 数据管理
- 训练数据导出为 JSON 文件
- 从 JSON 文件导入数据
- 自定义导出目录
- 调试日志查看器

### 🎨 界面设计
- Material Design 3 风格
- 日历首页，已完成训练日显示图标（🏋️ 力量 / 🏃 有氧 / 🏋️🏃 混合）
- 训练名言每日更换（冷启动时刷新）
- 底部五 Tab 导航：主页、模板、动作、统计、设置

## 技术栈
- Flutter + Dart
- SQLite (sqflite) 本地数据库
- 和风天气 API
- Geolocator + 高德 IP 定位
- Android Foreground Service（休息计时）
- AlarmManager 息屏精确闹钟
- MethodChannel 原生震动
