# FitTimer 💪⏱️

健身训练记录 + 组间休息计时器 Flutter App

## 功能特性

### 🏋️ 训练记录
- 按日期记录每次训练（点击日历日期进入训练页）
- 手动添加力量训练动作（名称、组数、重量、次数）
- 有氧训练支持（跑步、爬坡等，记录时长、距离、速度、坡度）
- 模板系统：保存常用训练方案，一键套用
- 训练中实时勾选完成组，自动记录实际重量和次数
- 草稿保存：未完成的训练自动保存为草稿

### ⏱️ 组间休息计时
- 可配置休息时长（默认90秒）
- 前台服务通知：锁屏/切后台计时不中断
- 连续震动提醒（可配置时长1/3/5秒）
- 训练语音/震动提示休息结束

### 📊 数据统计
- 周/月训练次数统计
- 个人记录（PR）：最佳重量、最佳训练量
- 自动过滤有氧运动，只统计力量训练 PR
- 时间段筛选：本周/本月/自定义日期范围

### 🌤️ 天气显示
- 首页实时天气（和风天气 API）
- GPS 定位 + 6小时缓存
- 每日首次加载获取，切页不重复请求

### 📤 数据管理
- 训练数据导出为 JSON 文件
- 从 JSON 文件导入数据
- 自定义导出目录
- 调试日志查看器（设置页）

### 🎨 界面设计
- Material Design 3 风格
- 日历首页，已完成训练日显示图标（🏋️力量 / 🏃有氧 / 🏋️🏃混合）
- 训练名言每日更换（冷启动时刷新）
- 可配置底部导航栏

## 技术栈
- Flutter + Dart
- SQLite (sqflite) 本地数据库
- 和风天气 API
- Geolocator 定位
- Android Foreground Service（休息计时）
- MethodChannel 原生震动
